# الزهراني – نظام محاسبي

تطبيق ويب تقدمي (PWA) محاسبي يعمل محليًا (`localStorage`) ويتزامن سحابيًا مع **Firebase Firestore**، مع دعم تصدير القوائم والقيود إلى **Excel (`.xlsx`)**.

## محتويات الحزمة
- `index.html`: الواجهة الكاملة للنظام المحاسبي (اليومية، الأستاذ، ميزان المراجعة، القوائم المالية، دليل الحسابات، تسجيل الدخول، والمزامنة مع Firestore).
- `manifest.json`: إعدادات التطبيق التقدمي (PWA) للتثبيت على الموبايل والكمبيوتر.
- `sw.js`: Service Worker لدعم العمل السريع وتخزين ملفات الواجهة محليًا.
- `icons/icon-192.png` و `icons/icon-512.png`: أيقونات التطبيق.

## ملاحظة مهمة حول قواعد أمان Firestore
تأكد أن قواعد Firestore في مشروعك تسمح بالقراءة والكتابة على المجموعات `users` و`journal_entries` و`activity_logs` أثناء الاختبار أو وفق سياسة الأمان المناسبة لمشروعك.

# الزهراني – نظام محاسبي

نظام محاسبي متكامل للقيد المزدوج، دفتر الأستاذ، ميزان المراجعة، والقوائم المالية (قائمة الدخل، المركز المالي، والتدفقات النقدية) مع تصدير إلى Excel، دعم العمل دون اتصال بالإنترنت، ومزامنة سحابية عبر **Firebase Firestore** (`al-zakrany`).

## خطوات الرفع على GitHub
1. ارفع ملفات المشروع (`index.html`, `manifest.json`, `sw.js`, `README.md`) إلى مستودعك على GitHub.
2. فعّل **GitHub Pages** من `Settings > Pages` (اختيار الفرع `main` وحفظ).
3. تأكد من تفعيل **Firestore Database** داخل مشروع `al-zakrany` في Firebase Console.

## مجموعات Firestore المستخدمة
- `users`: حفظ بيانات تسجيل الدخول (الاسم، رقم الهاتف، آخر دخول، ومعلومات المتصفح).
- `journal_entries`: حفظ القيود المحاسبية المرتبطة برقم هاتف المستخدم.
- `activity_logs`: سجل الأحداث (تسجيل الدخول، حفظ قيد، حذف قيد، مسح البيانات).
